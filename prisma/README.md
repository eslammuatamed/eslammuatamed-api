# `prisma` — المخطّط والترحيلات والبذور (Seeding)

> اقرأ `PROJECT_GUIDE.md` و`docs/09-database-design.md` أولًا. هذا المجلد يملك مخطّط قاعدة البيانات
> (`schema.prisma`)، وترحيلات `Prisma` المُلتزَمة (`migrations/`)، وسكربتات البذور. أسماء الملفّات
> والأوامر ومُعرّفات الشيفرة تبقى بالإنجليزية.

## المسؤولية

مصدر الحقيقة لبنية البيانات: النماذج، والتعداد (enums)، وجداول الترجمة لكل كيان (`D09-3`)، وجدول
`Locale` المرجعي (`D09-5`). الترحيل عبر `prisma migrate` فقط (`db:migrate` = `prisma migrate deploy`)،
والترحيلات ثابتة بعد الإصدار وتُطبّق عبر خطّ النشر لا يدويًّا في الإنتاج (`doc 23`).

## خريطة الملفّات

| الملف | الدور |
|---|---|
| `schema.prisma` | المخطّط: النماذج (PascalCase) ← أعمدة snake_case عبر `@map`/`@@map` (`D09-1`)، مفاتيح `uuid(7)` (`D09-2`)، جداول ترجمة لكل كيان (`D09-3`) |
| `migrations/` | ترحيلات `Prisma` المُلتزَمة والثابتة |
| `seed.ts` | **بذرة الإنتاج** (`npm run db:seed`): محايدة للتكرار (idempotent) — اللغات (`en`/`ar`)، دور `OWNER` (+ منحة `*`)، مستخدم `OWNER` (من متغيّرات البيئة)، صفّ `SiteSettings`، والفئات الأولية |
| `seed.dev.ts` | **طبقة بذرة التطوير/العرض فقط** (`npm run db:seed:dev`) — انظر أدناه (`D09-15`) |

## بذرة التطوير/العرض `seed.dev.ts` (`D09-15` · `D16-9`)

سكربت **للتطوير فقط**، منفصل تمامًا عن بذرة الإنتاج، **غير مربوط بمفتاح `seed` في `Prisma`** — لذا لا
يشغّله `prisma db seed` ولا الترحيلات، ويجب **ألّا يُشغَّل في الإنتاج أبدًا**. يعمل **فوق** بذرة الأساس:

```
npm run db:seed        # بذرة الأساس (اللغات + المالك + الإعدادات + الفئات)
npm run db:seed:dev    # طبقة التطوير/العرض (المحتوى ثنائي اللغة)
```

**ما يملؤه** (ثنائي اللغة `en` + `ar` لكل كيان مُترجَم): ملف `SiteSettings` (روابط التواصل + التوفّر +
`siteName`/`tagline`)، والمهارات، والخبرات، والمشاريع (مميّزة وغير مميّزة)، والتوصيات، والفئات،
والوسوم، ومجموعة مقالات مؤرَّخة. جميع مفاتيح الوسائط (cover/avatar/og) تُترك `null` (بلا اعتماد على
خطّ الوسائط/التخزين). حالة التوفّر (`availabilityStatus`) صارت **لكل لغة** (الميزة 007) — تُحفَظ على
صفوف الترجمة وتُحلّ حسب اللغة المطلوبة مثل `tagline` (بلا رجوع عبر اللغات).

**الضمانات:** محايد للتكرار (كلّ كتابة عبر فحص وجود مسبق أو `upsert` على مفتاح slug/طبيعي ثابت — بلا
`deleteMany`، بلا إعادة تعيين، بلا `UUID` ثابت)؛ المحتوى **مستمدّ من ملفّ المالك** بلا مقاييس ملفّقة
(`D02-2`)؛ الخبرات والروابط الاجتماعية حقيقية (Findropica / WeblyTech / WaveX؛ GitHub / LinkedIn /
البريد الرسمي).

**سلامة البيئة:** فحوص البيئة النظيفة تُجرى على قاعدة بيانات اختبار مؤقّتة عبر بيئة مؤقّتة خارجية —
**لا يُقرأ ملفّ `.env` المحلّي الحقيقي ولا يُكتَب ولا يُطبَع ولا يُعاد توليده**. القاعدة الكاملة في
`docs/16-development-conventions.md` §5.2 (`D16-9`) وآليّتها في `docs/09-database-design.md` §6 (`D09-15`).
